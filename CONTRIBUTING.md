# Contributing to Kanban Board! 🚀

Thank you for wanting to help make this Kanban board even better! To keep things smooth and simple, we have these instructions:

## 1. How to Code and Test 💻
This project is built with **React**, **Tailwind CSS**, and **Vite**.

1. **Fork** and clone the repository to your computer.
2. Create a new branch from `main` (e.g., `git checkout -b my-new-feature`).
3. Run `npm install` to get the dependencies.
4. Start the app locally with `npm run dev` and make sure your changes work.

## 2. Submit Your Code 🚀
When you are ready, open a **Pull Request** (PR) against the `main` branch.

* Keep your changes focused (fix one thing at a time).
* Write a short description of what you changed in your PR.
* We are building this together to learn and have fun!

Thanks for contributing! 🏄‍♂️
